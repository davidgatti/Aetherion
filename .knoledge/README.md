# Knowledge Base Navigation Guide

This centralized knowledge folder contains all documentation and project history to help both humans and AI understand the system.

## 📁 Directory Structure

### `instructions/` - System Patterns & Guidelines

- **[AGENTS.md](instructions/AGENTS.md)** - Core development philosophy and clean code patterns
- **[CONTRIBUTING.md](instructions/CONTRIBUTING.md)** - How to contribute to this project
- **[TESTING.md](instructions/TESTING.md)** - Comprehensive testing strategy and guidelines
- **[RELEASE.md](instructions/RELEASE.md)** - Complete release workflow and marketplace publishing

### `logbook/` - Project History & Changes

- Contains chronological records of what changed, when, and why
- Helps track project evolution and decision rationale

## 🎯 For New Contributors

1. **Start here:** Read [CONTRIBUTING.md](instructions/CONTRIBUTING.md)
2. **Understand the patterns:** Review [AGENTS.md](instructions/AGENTS.md)
3. **Learn testing:** Study [TESTING.md](instructions/TESTING.md)
4. **Check project history:** Browse `logbook/` for context

## 📋 File Organization Philosophy

This non-standard `.knoledge/` folder exists because:

- **AI-friendly:** Centralized documentation helps AI agents understand context
- **Better organization:** All knowledge in one place vs scattered files
- **Easier navigation:** Clear structure for both humans and automation
- **Complete context:** Everything needed to understand the project
